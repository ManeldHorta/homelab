# Diagrams

This directory contains diagrams representing the homelab architecture and operational flows.

Planned diagrams include:

- physical architecture;
- network topology;
- service architecture;
- Docker/service relationships;
- media processing flow;
- remote-access flow;
- future architecture.

Diagrams should describe the infrastructure without exposing sensitive operational information.

Recommended formats:

- Mermaid for diagrams that should remain editable in Git;
- SVG or PNG for rendered diagrams when useful.

Detailed internal network information should remain outside the public repository when it is not required to understand the architecture.
