# PCVR2



## Description



PCVR2 is a gaming computer connected to the homelab network.



Unlike PCVR1, PCVR2 currently does not host any homelab services.



Its primary purpose is gaming with less demanding games in terms of system resources.



## Role in the Homelab



PCVR2 is part of the homelab network infrastructure and has access to services and resources according to the established network policies.



It currently does not act as a server or Docker host.



## Current Usage



PCVR2 is mainly used for:



- Gaming

- Access to the homelab network



It is not currently used to host infrastructure, media or artificial intelligence services.



## Current Status



PCVR2 is a gaming computer connected to the homelab infrastructure but without any hosted services.



No homelab services are currently hosted on this system.
