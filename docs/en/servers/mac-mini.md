# Mac Mini



## Description



The Mac Mini is part of the homelab infrastructure and is currently used primarily to host services.



Unlike PCVR1 and PCVR2, its main role within the homelab is not gaming.



## Role in the Homelab



The Mac Mini acts as a host for Docker services.



It currently hosts Zabbix, which is used to monitor the homelab infrastructure.



## Services



### Zabbix



Zabbix runs inside Docker on the Mac Mini.



Its purpose is to monitor systems and services across the homelab infrastructure.



The specific Zabbix configuration is documented in the corresponding service documentation.



## Storage



The Mac Mini has limited local storage capacity.



This limitation was one of the reasons why UniFi OS was moved to PCVR1.



## Current Status



The Mac Mini is part of the permanent homelab infrastructure and hosts monitoring services.



The main documented service currently hosted on this system is Zabbix.
