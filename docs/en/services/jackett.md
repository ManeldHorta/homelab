# Jackett

## Description

Jackett is a Media Stack component that provides integration with compatible indexers.

## Function

Jackett is used to facilitate content discovery through configured indexers.

## Integration

It is part of the Media Stack ecosystem and interacts with content management and download services.

## Status

Jackett runs inside Docker on PCVR1.

Specific indexer configuration is not documented in the public repository when it may contain sensitive information.
