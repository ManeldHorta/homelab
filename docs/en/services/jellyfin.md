# Jellyfin

## Description

Jellyfin is the media playback and library management service.

It currently runs on PCVR1 inside Docker.

## Function

Jellyfin provides access to the video libraries managed by the Media Stack.

## Integration

Jellyfin primarily consumes:

- Movies
- TV series

The libraries are populated by the Media Stack and may be processed by Tdarr.

## Status

Jellyfin is part of the current PCVR1 media infrastructure.
