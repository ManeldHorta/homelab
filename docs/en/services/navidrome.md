# Navidrome

## Description

Navidrome is the music playback and library management service.

It currently runs on PCVR1 inside Docker.

## Function

Navidrome provides access to the music library managed by Lidarr.

## Integration

Main workflow:

Lidarr → qBittorrent → music library → Navidrome

Tdarr does not process this library.

## Status

Navidrome is part of the current PCVR1 media infrastructure.
