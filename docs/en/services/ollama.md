# Ollama

## Description

Ollama is one of the components of the local Artificial Intelligence infrastructure.

It runs on PCVR1 inside Docker.

## Function

Ollama provides the runtime environment for local AI models.

## Activation Policy

The PCVR1 AI infrastructure is only activated on demand to avoid interfering with gaming use.

## Privacy

The AI infrastructure is designed to keep data and processing within the local infrastructure.

## Status

Ollama is part of the PCVR1 local AI environment.
