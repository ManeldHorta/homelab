# Wi-Fi

## Current networks

The Wi-Fi infrastructure provides three functionally separated networks:

| Network | Main use | Band |
|---|---|---|
| PCVR | Gaming and virtual reality | 6 GHz |
| Dispositius | Laptops, mobile phones, and personal devices | 5 GHz |
| IoT | IoT and smart-home devices | 2.4 GHz |

The names PCVR, Dispositius, and IoT are functional names for the current Wi-Fi networks.

## VLANs

These Wi-Fi networks **do not currently correspond to real 802.1Q VLANs**.

The current separation is based on functional purpose and assigned wireless frequency bands.

## Access points

- U7 Pro
- U7 Lite

## Future

When a dedicated router is introduced, real VLANs are planned to separate networks by function and apply communication and firewall rules between them.
