# Internet and network access

## Current state

Internet connectivity is provided through Orange and a Livebox FIBRA.

The Livebox currently acts as the gateway for the local network and provides Internet access to infrastructure devices.

The public documentation does not include MAC addresses, credentials, or other sensitive infrastructure identifiers.

## Current architecture

Internet
   │
Orange
   │
Livebox FIBRA
   │
Network infrastructure

## Future

A dedicated router is planned to provide greater control over the network architecture, segmentation, and firewall rules.

The migration will be documented once the new router has been installed and validated.
