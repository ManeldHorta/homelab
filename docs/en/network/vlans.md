# VLANs

## Current state

There are currently **no real 802.1Q VLANs implemented** in the infrastructure.

PCVR, Dispositius, and IoT are functional Wi-Fi network names and must not be confused with network VLANs.

## Future plan

When a dedicated router is introduced, real VLAN-based segmentation is planned.

The intended separation will include at least:

- Gaming / VR
- Personal devices
- IoT

The final configuration, VLAN identifiers, and communication rules will be documented once the dedicated router has been installed and validated.
