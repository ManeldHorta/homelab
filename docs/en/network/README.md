
Network
Overview

This section documents the network infrastructure of the homelab.

The network provides connectivity between the Internet connection, local servers, Docker infrastructure, client devices and IoT equipment.

Internet

The Internet connection is provided through an Orange fibre connection.

The current network architecture and the final router configuration will be documented after the network inventory is completed.

UniFi

The homelab uses UniFi networking components.

The detailed inventory will document:

Router / gateway
Switches
Access points
Management infrastructure
VLANs
Wi-Fi networks
Firewall rules
DHCP
DNS
Internet connection configuration
VLANs

VLAN segmentation is used or planned for separating different types of devices and traffic.

The exact VLAN IDs, subnets and firewall rules will be documented after the network inventory.

Wi-Fi

The Wi-Fi infrastructure includes UniFi access points.

The final documentation will include:

SSIDs
VLAN assignment
Coverage
2.4 GHz configuration
5 GHz configuration
IoT network
VR network
Guest network, if applicable
Security

Network segmentation and firewall rules are used to limit unnecessary communication between network segments.

Sensitive network information is kept outside the public repository.
