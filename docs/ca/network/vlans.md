# VLANs

## Estat actual

Actualment **no hi ha VLANs 802.1Q reals implementades** a la infraestructura.

Les denominacions PCVR, Dispositius i IoT corresponen a xarxes Wi-Fi diferenciades per funció, però no s'han de confondre amb VLANs de xarxa.

## Planificació futura

Amb la incorporació d'un router propi es preveu implementar segmentació real mitjançant VLANs.

L'objectiu serà separar, com a mínim:

- Gaming / VR
- Dispositius personals
- IoT

La configuració definitiva, els identificadors de VLAN i les regles de comunicació es documentaran quan el router propi estigui instal·lat i validat.
