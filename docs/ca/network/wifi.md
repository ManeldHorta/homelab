# Wi-Fi

## Xarxes actuals

La infraestructura Wi-Fi proporciona tres xarxes diferenciades funcionalment:

| Xarxa | Ús principal | Banda |
|---|---|---|
| PCVR | Gaming i realitat virtual | 6 GHz |
| Dispositius | Portàtils, mòbils i dispositius personals | 5 GHz |
| IoT | Dispositius IoT i domòtics | 2,4 GHz |

Els noms PCVR, Dispositius i IoT són denominacions funcionals de les xarxes Wi-Fi actuals.

## VLANs

Actualment aquestes xarxes Wi-Fi **no corresponen a VLANs 802.1Q reals**.

La separació actual es basa en l'ús funcional de les xarxes sense fils i en les bandes de freqüència assignades.

## Punts d'accés

- U7 Pro
- U7 Lite

## Futur

Quan s'incorpori un router propi, es preveu implementar VLANs reals per separar les xarxes segons la seva funció i aplicar regles de comunicació i firewall entre elles.
