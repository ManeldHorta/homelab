# Internet i accés a la xarxa

## Estat actual

La connexió a Internet es proporciona mitjançant Orange i un Livebox FIBRA.

El Livebox actua actualment com a gateway de la xarxa local i proporciona l'accés dels dispositius de la infraestructura a Internet.

La documentació pública no inclou adreces MAC, credencials ni altres dades d'identificació sensibles.

## Arquitectura actual

Internet
   │
Orange
   │
Livebox FIBRA
   │
Infraestructura de xarxa


## Futur

Es preveu incorporar un router propi per disposar de més control sobre l'arquitectura de xarxa, la segmentació i les regles de firewall.

La migració es documentarà quan el nou router estigui instal·lat i validat.
