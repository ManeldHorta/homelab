# Dashy

## Descripció

Dashy és el dashboard web utilitzat com a punt d'accés als serveis del homelab.

Actualment s'executa a PCVR1 dins de Docker.

## Funció

Dashy proporciona una interfície centralitzada amb accessos als diferents serveis de la infraestructura.

## Estat

Dashy forma part dels serveis auxiliars actuals de PCVR1.
