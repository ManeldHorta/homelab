# Jackett

## Descripció

Jackett és un component del Media Stack que proporciona integració amb indexadors compatibles.

## Funció

Jackett s'utilitza per facilitar la localització de contingut mitjançant els indexadors configurats.

## Integració

Forma part de l'ecosistema del Media Stack i es relaciona amb els serveis de gestió de contingut i descàrrega.

## Estat

Jackett s'executa dins de Docker a PCVR1.

La configuració concreta dels indexadors no es documenta en el repositori públic quan pot contenir informació sensible.
