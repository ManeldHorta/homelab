# Portainer

## Descripció

Portainer és la interfície de gestió dels entorns Docker del homelab.

Actualment s'executa a PCVR1.

## Funcions

- Gestió de contenidors
- Gestió de stacks Docker
- Consulta de l'estat dels serveis
- Administració de recursos Docker

## Estat

Portainer forma part de la infraestructura de gestió Docker de PCVR1.
